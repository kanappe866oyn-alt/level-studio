記録: `output/desktop-v34-generate-report.json`、`output/desktop-v34-restore-report.json`、`output/desktop-v34-contract-report.json`。既存の利用者プロファイルは変更していない。クラウドAIは呼び出していない。

ブラウザ版の生成・編集・確認・保存の機能を同梱し、開発サーバーの手動起動なしで開けます。0.1.21では[エディタの白画面からの復帰と全体検査](stabilization-v27.md)と、確認中も操作できる検査Workerを同梱しました。

## 起動

`releases/0.1.33/LevelStudio-win32-x64/LevelStudio.exe` を開きます。隣のDLL・resources・localesを含むフォルダ全体が必要です。実行ファイルだけを別の場所へ移さず、移動する場合はフォルダごとコピーしてください。Node.jsや開発サーバーを起動する操作は不要です。

これはインストーラー付きの正式配布版ではなく、試作フォルダです。過去の版は残しています。旧版を開いている間は旧版の画面に戻るため、最新版へ切り替える際は作品を保存して旧版を閉じてから起動してください。保存領域は共通で、作品を作り直す必要はありません。

## 作品を使う

- ブラウザ版の「保存」で残したJSONを、アプリの「その他の操作」→「開く」から読み込めます。
- 最近の作業はアプリ内へ最大5件自動保存し、起動時の「保存した作業を再開」から戻れます。ブラウザ版とは保存領域が別で、自動同期はしません。
- 「保存」で編集用JSON、「GLB出力」で3Dモデルを書き出します。Windowsの保存先を選ぶ画面が開きます。
- 構造ルールでの生成にAPIキーは不要です。AI機能は別途設定が必要で、ローカルAIサーバーやAIモデル本体はアプリに同梱していません。

通常利用の保存領域は `%APPDATA%/LevelStudio`。起動・終了を跨いで保持します。検査専用の保存領域 `output/desktop-smoke-profile` とは別です。大切な作品はJSONでも残してください。0.1.14の大きい自動保存は圧縮形式になるため、再開には最新版を使ってください。旧版へ作品を渡す場合はJSONで保存して開きます。

## 実装と検証記録

Electron 44.9.0、Electron Packager 20.3.0、Windows x64。モデル、画面、Workerを含むビルド済みファイルだけをアーカイブに同梱し、`.env`、AIサーバー、訓練データ、開発用node_modulesは含めません。

同梱先以外へのファイル読み込みを防ぐパス確認、コンテキスト分離、レンダラーのサンドボックス、Node機能の非公開、外部ナビゲーションの制限を実装。アプリ側に新しいファイル操作用の通信窓口は設けず、既存のファイル選択とダウンロードの仕組みを使います。[Electron公式のプロトコル説明](https://www.electronjs.org/docs/latest/api/protocol)、[安全な構成の説明](https://www.electronjs.org/docs/latest/tutorial/security)を参照しました。

開発時は `npm run desktop:run`。配布フォルダは `npm run desktop:package` で作成します。既存の版を上書きしない設定なので、再配布の際は `tools/package_desktop.mjs` の版を更新します。自動検査は `desktop/smoke.mjs`、パス・ナビゲーションの検査は `tests/desktopBundle.test.mjs` にあります。

成果物は `output/desktop-ui-project.json`、`output/desktop-ui-stage.glb`。検査記録は `output/desktop-*-report.json` と `output/desktop-*.log`。

## 残る確認

他のPCへの持ち込み、インストーラー、署名、更新機構、AI接続の実機確認は未実施です。環境光HDRの読み込みは既存の任意のネットワーク処理を共有しており、失敗時は標準照明へ戻ります。外部通信なしでの全景観の比較は未実施です。
