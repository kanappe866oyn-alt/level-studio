# 坂・階段の必要長を保持する配置補正

2026-10-21。AI空間設計の組立が失敗した場合、座標列の間隔をプログラムで広げる候補を作る。広場の幅・奥行、高さ、通路幅、曲がり、接続グラフ、要求する独立経路と視線は変更しない。同じ座標のエリアは一緒に移動し、出口の整列と位置の順序を維持する。既存の間隔は縮めない。

坂は高低差の3倍、階段は1.2倍、曲線は変位の3倍および既存の最小長を確保する。1m単位で計算し、中心座標±48mに収まらない候補は採用しない。通常の組立に成功した案には補正を行わない。補正後も組立・指定条件・歩行・射線・仕上げ後検査を通す。解決しない問題は従来の最大3回のAI設計へ戻す。

- 関連32テスト成功。誤った射線条件は補正後も失敗し、3回で終了する。
- 決定的な合成24ケース（広場8/10/12m、直線/曲線の坂、4方向配置）：補正前0件、補正後24件が構造・歩行・射線検査を通過。各ケース3独立経路、11接続の往復を確認。
- 通常の仕上げを含む試験で、1回のテスト用設計応答から補正・生成が完了。
