# LEVEL STUDIO

文章や参考画像から3Dステージを組み立て、編集・歩行確認・JSON保存・GLB出力ができる試作ツールです。

## 公開先

- Web版: https://kanappe866oyn-alt.github.io/level-studio/
- Windows版: https://github.com/kanappe866oyn-alt/level-studio/releases/tag/v0.1.42

Web版はGitHub Pagesで公開しています(旧Netlifyのサイトは更新しません)。Web版とWindows版 v0.1.42 は同じソースから作っています。

v0.1.42: エディタの初期モードを「自由制作」にしました(以前の「対戦アリーナ」では、川や橋を含む普通の指示が要求整理の段階で止まっていました)。対戦アリーナでも、モードが必要とする遮蔽物・タワー・スポーンの最低数を利用者の指定として扱わず、アプリが作る川・岩・植栽を使えるようにし、地形の上に浮いたタワーや遮蔽物を地面に置きます。「遮蔽物が多く」のような曖昧な数量を、利用者が指定した厳密な個数として扱わないようにしました。対戦モードの標準スポーン数も、利用者の引用として要求しません。明示した個数や禁止条件の検査は維持します。GitHub Pagesのサブパスからモデル・材質・画像を読み込めるようにしました。

## 利用方法と制約

サンプルの編集・歩行確認・保存にはAPIキー不要です。AI生成は利用者自身のGemini APIキーと利用枠が必要です。すべての指示での生成成功や画像の完全再現は保証しません。滝・砂浜は未対応です。

作品の自動保存はブラウザのサイトごとに別です。旧サイトの作品はJSONで保存し、新しいサイトで開いて移してください。Windows版とWeb版もJSONで作品を移せます。

## 開発

Node.js 22.12以降で `npm ci`、`npm run dev` を実行します。`npm test` は公開ソースに含む回帰テスト、`npm run build` は通常のビルドです。

## 公開

GitHub Pagesのgh-pagesブランチから公開します。Pages向けビルドでは `LEVEL_STUDIO_BASE=/level-studio/` を指定し、生成されたdistの内容と.nojekyllをgh-pagesへ送ります。mainへのソース更新だけではWeb版に反映されません。Windows向けビルドにはこの設定を付けません。

公開するソースは許可リストで準備します。`.env`、APIキー、個人データ、保存作品、評価データ、バックアップをアップロードしないでください。共通APIキーをビルドの環境変数へ設定しないでください。

Windows ZIPはGitHub Releasesで配布します。現在のリンクはv0.1.42です。更新時はソース・タグ・ZIPの対応を確認してください。

素材のクレジットはアプリのトップ画面にあります。Windows版はZIPをすべて展開してLevelStudio.exeを起動します。
